# 附件说明（题目：内容运营后台 CLI 化）

本题共两份附件：

## 1. content-ops-admin-openapi.json（内容运营后台接口）

从现有系统导出的接口文档（OpenAPI 3.0 格式）。共 21 个接口路径、23 个操作，覆盖内容查询、审核、标签、分发、状态调整、创作者与白名单、用户举报、站内通知、推荐位、异步导出、统计与操作日志。每个接口带请求示例（`x-request-example` 字段）与响应示例。

说明：

- 接口基本可用，但并不是为 CLI 或 Agent 调用专门设计的；文档中描述的行为即当前系统的真实行为。
- `servers` 中的地址为示例占位，不可访问。

## 2. mock_data.json（样例数据）

与接口字段口径一致的样例数据，可作为本地假数据源驱动你的方案（例如 mock 接口返回、驱动演示或验证）。不要求真实联网调用。

包含七部分：

| 键 | 内容 | 规模 |
|---|---|---|
| `contents` | 内容列表（含详情字段） | 300 条 |
| `creators` | 创作者列表 | 40 位 |
| `review_logs` | 内容审核记录，按 content_id 索引 | 174 组 |
| `reports` | 用户举报 | 30 条 |
| `promo_slots` | 推荐位占用 | 6 条 |
| `tags` | 标签库 | 25 个 |
| `categories` | 分发栏目与可用渠道 | 3 个 |

数据为虚构样例，分布与真实系统近似，但不保证每条记录都干净、一致。
